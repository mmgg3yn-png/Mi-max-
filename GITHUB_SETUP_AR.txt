إعداد مشروع MiMax Ai على GitHub

1) أنشئ مستودعاً جديداً على GitHub.
2) ارفع محتويات هذا المجلد إلى جذر المستودع (بما فيها .gitignore ومجلد .github).
3) عند كل push إلى main أو master، سيعمل GitHub Actions تلقائياً على بناء نسخة Debug APK.
4) للحصول على APK: افتح تبويب Actions، اختر آخر عملية Build MiMax Ai Android، ثم نزّل MiMaxAi-debug-apk من Artifacts.

ملاحظة مهمة:
مجلد .git ليس ملفاً نرفعه يدوياً. ينشئه Git محلياً عند تنفيذ git init، أو ينشئه GitHub تلقائياً عند إنشاء المستودع وربط المشروع. الملف .gitignore ومجلد .github هما ما أعددناهما داخل المشروع.

هذا إعداد لبناء Debug فقط، وليس إصدار Release موقعاً للنشر.
لا تضع مفاتيح API أو كلمات مرور أو مفاتيح توقيع داخل مستودع عام.
